# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Beacon seriously. If you believe you have found a security vulnerability in Beacon, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email describing the vulnerability, proof of concept, and affected versions to `kachakaran06@gmail.com` or use [GitHub Security Advisories](https://github.com/kachakaran6/beacon/security/advisories/new).
3. We will acknowledge receipt within 48 hours and work on a fix as quickly as possible.
